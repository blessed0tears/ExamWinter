Разработка основных модулей для ООО «Ароматный мир»

Данный проект представляет собой настольное приложение FragrantWorldApp, разработанное для автоматизации и управления внутренними процессами компании ООО «Ароматный мир». 
Приложение реализовано на платформе .NET 8.0 (WPF) и включает модули авторизации, корзины, управления товарами и оформления заказов.
